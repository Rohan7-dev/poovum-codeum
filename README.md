# 🌸 Poovum Codeum - Interactive Pookalam Designer

A digital, interactive Pookalam designer built for the Poovum Codeum Onam coding competition at NSS College of Engineering. 

## Features
* **Auto-Blooming:** Instantly loads a complete, densely packed, rotating floral carpet.
* **Interactive Canvas:** Click and drag to customize the design with symmetry controls and undo history.
* **Intricate Motifs:** Authentic, layered designs including Lotus, Marigold, and Mango Paisley.
* **Export:** One-click save to PNG with a custom watermark.
* **Zero Dependencies:** Built entirely with plain HTML, CSS, and Vanilla JavaScript in a single file.
## Setup / How to Run
This is a single self-contained HTML file with no dependencies or build step.

1. Clone or download this repository
2. Open `index.html` directly in any modern browser

No installation required.
